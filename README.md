# CS:GO Stealth External ESP

Высокопроизводительный внешний оверлей для CS:GO, разработанный с упором на скрытность при демонстрации экрана и минимальную нагрузку на систему.

## Основные возможности

*   **Stream-Proof Отрисовка**: Оверлей полностью невидим для OBS, Discord, системных скриншотов и других программ захвата. Это реализовано через аппаратный флаг `WDA_EXCLUDEFROMCAPTURE`.
*   **Double Buffering**: Использование двойной буферизации (GDI MemDC) исключает мерцание линий и боксов даже при высоком FPS.
*   **Оптимизация чтения**: Пакетное чтение памяти (чтение структур целиком вместо отдельных переменных) снижает количество вызовов `ReadProcessMemory`.
*   **Стелс-запуск**: Компилируется в файл с системным именем `SystemUtility.exe` и работает без консольного окна.

## Техническая база

*   **Язык**: C++ 17
*   **Графика**: Win32 GDI (не требует DirectX/ImGui)
*   **Метод**: External (без инъекции в процесс игры)
*   **Маскировка**: Layered Windows + Display Affinity API

## Структура проекта

*   `main.cpp` — Логика поиска игры, цикл чтения памяти и WorldToScreen преобразования.
*   `Overlay.h` — Создание прозрачного окна и реализация защиты от захвата.
*   `Memory.h` — Обертка для безопасного доступа к памяти процесса.
*   `offsets.h` — Смещения для актуальной версии игры.

## Инструкция по сборке

### Требования
*   Windows 10/11 (версия 2004 или новее для работы скрытия).
*   Visual Studio 18 (2026) или новее с установленной нагрузкой "Разработка классических приложений на C++".

### Сборка через интерфейс VS
1. Создайте пустой проект C++ (Windows Desktop Application).
2. Добавьте все файлы (`.cpp` и `.h`) в проект.
3. В настройках проекта:
   *   **Configuration**: Release
   *   **Platform**: x86 (обязательно!)
   *   **Linker -> System -> SubSystem**: Windows (`/SUBSYSTEM:WINDOWS`)

### Быстрая сборка через CMD
В папке с проектом уже есть файл `build.bat`. (Может потребоваться изменения пути к Vs)
1. Откройте командную строку.
2. Запустите `build.bat`. 
3. На выходе вы получите файл `SystemUtility.exe`.
